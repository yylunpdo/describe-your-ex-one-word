An entry for the [make.fun](https://make.fun) bounty **Describe Your Ex in One Word** — sum up an ex in exactly one word.

## The word

**unsubscribed**

The ex as a subscription you finally cancelled. No renewal, no refund, no "we miss you" email.

## How it works

`main.py` (Python standard library only, fully deterministic) writes the single word to `/output/entry.txt`. Run it twice and the output is byte-identical every time:

```sh
python3 main.py
```

## Entry

- Program: `main.py`
- Output: `/output/entry.txt` — one word, 12 characters, no spaces
